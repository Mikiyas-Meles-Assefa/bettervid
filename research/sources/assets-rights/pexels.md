# Pexels API (retrieved 2026-10-29) https://www.pexels.com/api/documentation/
- Header Authorization: KEY. "200 requests per hour and 20,000 requests per month." Higher limit free on request; apps meeting terms may get unlimited.
- Videos: GET /v1/videos/search (size large=4K, medium=FullHD, small=HD; per_page max 80), /v1/videos/popular. video_files with link, fps, width.
- "Every API use must include a prominent link to Pexels"; credit photographers when you can. Cannot replicate Pexels core functionality.
