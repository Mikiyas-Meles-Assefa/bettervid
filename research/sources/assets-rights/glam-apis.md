# GLAM / archive APIs (retrieved 2026-10-29)
- Internet Archive advancedsearch live: collection:prelinger AND mediatype:movies numFound 10461; field licenseurl returns e.g. http://creativecommons.org/licenses/publicdomain/ . Prelinger help https://help.archive.org/help/prelinger-archive/ : "DO NOT ASSUME that all Prelinger Archives films are in the public domain"; suggested credit "Archival footage supplied by Internet Archive (at archive.org) in association with Prelinger Archives"; descriptions/shotlists metadata copyrighted (Prelinger+Getty), no commercial reuse. [reported via search snippet]
- Smithsonian Open Access: https://api.si.edu/openaccess/api/v1.0/search?q=apollo&api_key=DEMO_KEY works live; response header x-ratelimit-limit: 10 (DEMO_KEY). Real key is free via api.data.gov (not signed up). Items carry CC0 flag in content.descriptiveNonRepeating.metadata_usage. [limits verified live, CC0 field unverified]
- Rijksmuseum: new https://data.rijksmuseum.nl/search/collection?type=painting&creator=Rembrandt returned Linked Art JSON, no key (live). IIIF images. CC0 "wherever possible". Legacy rijksmuseum.nl/api with key is old. https://data.rijksmuseum.nl/about/
- Europeana: wskey required (api2demo works for tests), reusability=open filters open content, rights in edm:rights. "Only the metadata is CC0. The linked media files do not fall under CC0". https://pro.europeana.eu/page/available-rights-statements
- NYPL Digital Collections Repo API: "will no longer be available starting August 1st, 2026. No public API replacement" (search snippet from https://api.repo.nypl.org/). Fallback: CC0 metadata on GitHub NYPL-publicdomain/data-and-utilities. Live curl of api.repo.nypl.org returned HTTP 200 HTML only.
- LoC: loc.gov/apis overview: JSON via ?fo=json, IIIF image services. Live curl from this machine hit a Cloudflare "Just a moment" challenge (bot block), so it needs a polite UA/low rate. Rights per item, not blanket.
