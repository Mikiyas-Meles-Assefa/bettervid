# bettervid

Turn a research paper or a technical topic into an accurate, well-researched explainer video.

Built for the [Meta Global AI Developer Hackathon](https://cerebralvalley.ai/e/meta-ai-developer-hackathon) (Oct 27 – Nov 4, 2026). All code in this repo was written during the event.

## Stack

- Muse Spark: research grounding, scripting, scene planning, code generation, visual critique
- Muse Image: keyframes and illustrations
- SAM 3.1: layer decomposition for 2.5D motion
- Manim: exact math and diagram animation
- Modal Sandboxes: isolated rendering of generated code
